> [!TIP]
> This is a blog theme based on the [Astro](https://astro.build) framework and the [Fuwari](https://github.com/saicaca/fuwari) template.
>
> Much of the project content was translated with AI. If you spot an issue, please submit a [Pull Request](https://github.com/ancryel/fuwari-modified/pulls) with a correction.

## ✨ Features

Building on Fuwari's elegant design and reading experience, this project includes the following updates and additions:

### &nbsp;&nbsp;Technology Updates
- [x] Upgraded to Astro v5
- [ ] Upgrade to Astro v7
- [x] Replaced Svelte with Alpine.js
- [x] Upgraded to Tailwind v4
- [ ] Upgrade to TypeScript v6

### &nbsp;&nbsp;Feature Enhancements
- [x] Background image with translucent cards
- [x] Homepage text
- [x] Scroll progress bar

## 📖 Usage

| Item | Path |
|:---|:---|
| Site configuration | `src/config.ts` |
| Posts | `src/content/posts/` |
| About page | `src/content/spec/about.md` |

> For deployment, theme customization, project structure, and more, see the [original Fuwari README](https://github.com/saicaca/fuwari#readme).
