> [!TIP]
> 這是一款以 [Astro](https://astro.build) 框架和 [Fuwari](https://github.com/saicaca/fuwari) 範本為基礎修改的部落格主題。
>
> 專案中有許多內容由 AI 翻譯，如有不準確之處，歡迎提交 [Pull Request](https://github.com/ancryel/fuwari-modified/pulls) 協助修正。

## ✨ 功能特色

在保留 Fuwari 原版優雅設計與閱讀體驗的基礎上，完成了以下修改與新增：

### &nbsp;&nbsp;技術升級
- [x] 升級至 Astro v5
- [ ] 升級至 Astro v7
- [x] 以 Alpine.js 取代 Svelte
- [x] 升級至 Tailwind v4
- [ ] 升級至 TypeScript v6

### &nbsp;&nbsp;功能強化
- [x] 背景圖片 + 卡片透疊效果
- [x] 首頁文字
- [x] 捲動進度條

## 📖 使用說明

| 項目 | 路徑 |
|:---|:---|
| 網站設定 | `src/config.ts` |
| 文章 | `src/content/posts/` |
| 關於頁面 | `src/content/spec/about.md` |

> 部署、主題自訂、專案結構等更多內容，請參閱 [Fuwari 原版 README](https://github.com/saicaca/fuwari#readme)。

## 🙏 特別感謝

本專案以 [saicaca](https://github.com/saicaca) 開發的 [fuwari](https://github.com/saicaca/fuwari) 範本為基礎。

Astro 5 · Alpine.js 3 · Tailwind CSS 4 · TypeScript 5.9

Pagefind · Expressive Code · KaTeX · PhotoSwipe · Swup
